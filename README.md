# csharp-journey

Мой путь к стажировке .NET-разработчиком: решения задач, учебные проекты и заметки о прогрессе.

## Что здесь лежит

| Папка | Что внутри |
|---|---|
| `algo/` | Решения задач по алгоритмам на C# (Codeforces и тренировочные контесты) |
| `tasks/` | Задания от ментора: что сделать и как проверить результат |
| `TOPICS.md` | Темы, которые я применил в коде и должен законспектировать |

## Как запустить решение задачи

Нужен .NET SDK 10. Каждое решение — один файл, проект не нужен:

```bash
dotnet run algo/cf/4A.cs < input.txt
```

## Правила

- Код пишу сам. Ментор даёт задания и ревью.
- Каждая рабочая итерация — коммит.
- Конспект темы пишу после того, как применил её в коде.
